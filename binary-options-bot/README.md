# بوت Pocket Option — نسخة الكمبيوتر (أتمتة متصفح على الديمو)

بوت تداول آلي على حساب **Pocket Option التجريبي**، بيشتغل **زي الإنسان بالظبط**: بيفتح متصفح Chrome حقيقي، و**انت بتسجّل دخولك بنفسك**، والبوت بيضغط أزرار **CALL / PUT** في واجهة الموقع بس.

**مفيش SSID، مفيش API، مفيش أي بيانات دخول في الكود — إطلاقاً.**
القرار بيتاخد من **محرك استراتيجيات كامل** (مؤشرات + فلاتر)، على أسعار عامة من Yahoo Finance.

> ⚠️ **اقرأ التحذيرات دي الأول، قبل ما تشغّل أي حاجة.**

## ⚠️ تحذيرات مهمة — ديمو بس، ومخاطرة حظر

1. **ديمو بس، ولأسابيع.** البوت معمول لحساب الديمو الحقيقي. متستخدمش فلوس حقيقية غير بعد اختبار أسابيع على الديمو، وتشوف بنفسك نتايجه في `trades.csv`. ولو قررت يوماً ما تستخدم فلوس حقيقية، فده على مسؤوليتك الكاملة وبمبلغ تقدر تخسره كله.
2. **أتمتة الواجهة برضه مخالفة لشروط المنصة.** حتى لو من غير SSID ولا API، إن برنامج يضغط الأزرار بدالك مخالف لشروط استخدام Pocket Option، والمنصة ممكن **تكتشف النمط الآلي وتحظر الحساب — حتى على الديمو**. التأخيرات العشوائية بتقلل الخطر بس مش بتلغيه. ده للتعلم والتجربة على الديمو فقط.
3. **مفيش أي ضمان ربح.** الخيارات الثنائية مخاطرتها عالية جداً، وممكن تخسر كل المبلغ. البوت ده أداة تعليمية وتجريبية، مش آلة فلوس.
4. **نقطة التعادل حوالي 52%.** لو العائد 92%، الصفقة الكسبانة بتديك 0.92 دولار على كل دولار، والخسرانة بتاخد الدولار كله. عشان تتعادل بس، لازم تكسب أكتر من **52%** من الصفقات (100 ÷ 192 ≈ 52.1%). أي استراتيجية نسبة فوزها أقل من كده بتخسر على المدى الطويل.
5. **المارتينجال مقفول.** مضاعفة المبلغ بعد كل خسارة مش موجودة في الكود أصلاً (`MARTINGALE = False` في `config.py`)، لأنها أسرع طريق لتصفير الحساب.
6. **ليه مش بنستخدم BinaryOptionsTools؟** دي أقوى مكتبة مفتوحة المصدر لقيناها على GitHub (ChipaDevTeam/BinaryOptionsTools-v2 — ‏140 نجمة)، بس هي بتحتاج **SSID** بتاع جلستك عشان تتصل بالمنصة مباشرة، وده بالظبط اللي المستخدم رفضه: اتصال مباشر بالحساب مخالف للشروط وأسهل في الكشف والحظر. عشان كده مذكورة هنا كمرجع بس، ومش مستخدمة في أي كود في المشروع ده.

## 🧠 محرك الاستراتيجيات (مش مجرد زر شراء/بيع)

البوت ده فيه محرك كامل، والقرار بيتاخد على 3 مراحل: **مؤشرات → استراتيجية → فلاتر**.

### المؤشرات — `indicators.py`
| المؤشر | الاستخدام |
|---|---|
| EMA 9 / 21 / 50 | اتجاه الترند (قصير/متوسط/طويل) |
| RSI 14 | تشبع شراء/بيع + قوة الترند |
| Stochastic 14,3,3 | تقاطع %K/%D في مناطق التشبع |
| MACD 12,26,9 | زخم الترند (الخط والإشارة والهيستوجرام) |
| Bollinger Bands 20,2 | التذبذب + قرب السعر من الحدود |
| Alligator (13/8/5) | ترند بيل ويليامز: الفك/الأسنان/الشفاه |
| ATR 14 | قياس التذبذب (للفلاتر) |

اختبارهم: `python indicators.py` — فيه اختبارات بسيطة (ترند صاعد لازم EMA9 > EMA21 > EMA50، و RSI عالي... إلخ).

### الاستراتيجيات — `strategies.py` (قابلة للتبديل)
بتتغيّر من `config.py` (سطر `STRATEGY`) أو من سطر الأوامر `--strategy`:

| # | الاستراتيجية | الفكرة |
|---|---|---|
| 1 | `trend_ema_rsi` | ترند: EMA9 فوق EMA21 + السعر فوق EMA9 + RSI تحت 65 → CALL (والعكس PUT) |
| 2 | `reversal_rsi_stoch` | انعكاس: RSI تحت 30 + Stochastic طالع من تحت 20 → CALL (والعكس PUT) |
| 3 | `pullback` | ترند EMA50 + ارتداد: السعر فوق EMA50 و RSI نزل لـ 35-50 وبيرجع → CALL |
| 4 | `alligator_rsi` | التمساح مرتب لفوق (شفاه > أسنان > فك) + السعر فوق الشفاه + RSI تحت 65 → CALL |
| 5 | `confluence` ⭐ (الافتراضية) | **دخول بس لو 3 مؤشرات على الأقل اتفقوا** على نفس الاتجاه (EMA + RSI + Stochastic + MACD + Bollinger + Alligator) |

كل استراتيجية بترجّع الاتجاه + **قائمة المؤشرات اللي وافقت** (`votes`) + سبب — والبوت بيسجّل التلاتة في كل صفقة في `trades.csv`.

### الفلاتر — `filters.py` (بتتفحص قبل أي دخول)
لو أي فلتر رفض، **مفيش صفقة** حتى لو الاستراتيجية قالت ادخل:

| الفلتر | بيرفض إمتى |
|---|---|
| `trend_filter` | الاتجاه عكس الترند (EMA9/21/50 مش مرتبين معاه) |
| `payout_filter` | العائد أقل من **85%** (الافتراضي `MIN_PAYOUT`) — لأن نقطة التعادل بتبقى عالية أوي |
| `sideways_filter` | سوق عرضي أو تذبذب منخفض (خطوط EMA متقاربة، أو Bollinger bandwidth ضيق) |
| `time_filter` | برّه ساعات التداول المسموحة (`ALLOWED_HOURS` / `BLOCKED_HOURS` في `config.py`) |
| `best_asset_filter` | اختيار أفضل أصل من كذا مرشح حسب قوة الترند (دالة جاهزة، بتستخدمها لو بتقارن أصول) |

## 🖥️ التشغيل على الكمبيوتر (ويندوز)

**المتطلبات:** Python 3.10 أو أحدث.

### الطريقة السهلة (دبل كليك)
1. نزّل Python من [python.org](https://www.python.org/downloads/)، وعلّم على **Add Python to PATH**.
2. انسخ مجلد البوت على جهازك.
3. دوس دبل كليك على `run.bat` — هيثبّت المكتبات والمتصفح ويشغّل البوت في الوضع الورقي.

### الطريقة اليدوية
```bat
pip install -r requirements.txt
playwright install chromium
python bot_browser.py
```

### خطوات التشغيل (بالترتيب)
1. **قارن الاستراتيجيات الأول:**
   ```bash
   python backtest.py
   python backtest.py --csv candles.csv --stake 1 --payout 0.92
   ```
   هيطبع جدول: كل استراتيجية ونسبة فوزها وصافي ربحها. اللي تحت 52% بتخسر — متعتمدش عليها.
2. **جرّب الإشارات لوحدها (من غير متصفح):**
   ```bash
   python signals.py --once
   python signals.py --strategy trend_ema_rsi
   ```
3. **شغّل البوت في الوضع الورقي** (الافتراضي `DRY_RUN=True` في `config.py`):
   ```bash
   python bot_browser.py
   ```
   هيفتح Chrome، **هتسجّل دخولك بنفسك**، وتبدّل للديمو بنفسك. البوت هيتأكد من كلمة Demo في الواجهة، وهيقولك كان هيضغط إيه — من غير ما يضغط أي زر. راجع `trades.csv` أيام/أسابيع.
4. **التنفيذ الحقيقي على الديمو** (بعد ما تطمّن):
   ```bash
   python bot_browser.py --live
   ```
   أو غيّر `DRY_RUN = False` في `config.py`. البوت هيطلب تأكيدك بكتابة `YES` في الطرفية قبل أول صفقة، وهيضغط CALL/PUT فعلاً — على الديمو بس. للإيقاف: Ctrl+C، أو زر STOP الأحمر على الصفحة، أو اعمل ملف `stop.txt` جنب البوت.

### إزاي البوت بيتأكد إن الحساب ديمو؟
- بيقرا نص الواجهة وبيدوّر على كلمة **Demo** جنب الرصيد. لو مش لاقيها، بيوقف نفسه فوراً.
- في وضع التنفيذ، بيطلب تأكيدك بكتابة `YES` قبل أول صفقة.
- ولو في أي لحظة الرصيد أو الواجهة اتغيّرت، البوت بيوقف بأمان بدل ما يضغط غلط.

### ملحوظة عن الأزرار
تصميم موقع Pocket Option ممكن يتغيّر. البوت بيجرّب كذا محدد (selector) لزر CALL/PUT وخانة المبلغ، ولو ملقاش أي واحد، **بيلغي الصفقة وبيسجّل السبب** بدل ما يضغط حاجة غلط. لو ده حصل كتير، حدّث المحددات في دالة `click_direction` في `bot_browser.py`.

## 📱 البديل على أندرويد: Kiwi Browser + Tampermonkey

ده خيار إضافي لو الكمبيوتر مش متاح — **نفس المنطق، جوّه المتصفح نفسه**:

1. نزّل **Kiwi Browser** من Google Play.
2. نزّل إضافة **Tampermonkey** من Chrome Web Store جوّه Kiwi.
3. افتح ملف `pocket-option-auto.user.js` في Kiwi — Tampermonkey هيسألك تثبّته، دوس Install.
4. افتح Pocket Option في Kiwi، **سجّل دخولك بنفسك، وبدّل للديمو بنفسك**.
5. لوحة تحكم صغيرة هتظهر على الصفحة: اختار الاستراتيجية، ودوس **START**. للإيقاف دوس **STOP** في أي وقت (أو اقفل التبويب).
6. السكربت بيجمع السعر من الصفحة، بيبني شموع 60 ثانية، وبيحسب نفس المؤشرات والاستراتيجيات، وبيضغط CALL/PUT بتأخيرات عشوائية، مع نفس حدود المخاطر (حد صفقات/خسارة يومية، إيقاف بعد 3 خساير، فلتر عائد 85%).

**تحذيرات أندرويد:** نفس تحذير الحظر — أتمتة الواجهة مخالفة للشروط حتى على الديمو. ولازم التليفون يفضل شغال والتبويب مفتوح؛ لو النظام قفل Kiwi في الخلفية، السكربت هيقف. ومفيش أي بيانات دخول في السكربت — انت اللي بتسجّل بنفسك.

## ⚙️ الإعدادات (في `config.py`)

| الإعداد | الافتراضي | معناه |
|---|---|---|
| `STRATEGY` | `confluence` | الاستراتيجية (الخمسة اللي فوق) |
| `SYMBOL` | `EURUSD=X` | مصدر الأسعار العام للقرار (Yahoo Finance) |
| `ASSET_ON_POCKET` | `EURUSD` | اسم الأصل في Pocket Option — استخدم الزوج الحقيقي في ساعات السوق، مش OTC |
| `EXPIRY` | `60` | مدة الصفقة بالثواني |
| `STAKE` | `1.0` | مبلغ الصفقة بالدولار (ديمو، صغير جداً) |
| `MIN_PAYOUT` | `0.85` | فلتر العائد: مفيش دخول لو العائد < 85% |
| `MAX_TRADES` | `10` | أقصى صفقات في اليوم |
| `DAILY_LOSS_LIMIT` | `10.0` | أقصى خسارة يومية — البوت بيوقف لما يوصلها |
| `MAX_CONSECUTIVE_LOSSES` | `3` | إيقاف بعد 3 خساير ورا بعض |
| `COOLDOWN_SECONDS` | `75` | انتظار بين الصفقات |
| `DRY_RUN` | `True` | ورقي (من غير ضغط) — غيّره لـ `False` بس بعد اختبار الديمو |
| `HEADLESS` | `False` | لازم يفضل False — انت لازم تشوف المتصفح |

**ملحوظة مهمة عن الأسعار:** القرار مبني على أسعار **السوق الحقيقي** (Yahoo Finance)، مش على أسعار OTC بتاعة المنصة. عشان كده استخدم الأزواج الحقيقية في ساعات السوق، ومتتوقعش تطابق كامل مع سعر المنصة لحظة بلحظة — الفرق ده سبب إضافي للاختبار الطويل على الديمو قبل أي قرار.

## 📊 سجل الصفقات — `trades.csv`

كل صفقة بتتسجل بالتفصيل: التاريخ، الاتجاه، المبلغ، المدة، سعر الدخول، **الاستراتيجية**، **المؤشرات اللي وافقت** (`votes`)، الفلاتر، العائد، RSI، النتيجة والربح. راجع الملف ده وحاسب البوت بالأرقام: أي استراتيجية بتكسب؟ وأي فلتر بيمنع خساير؟

## ❓ مشاكل شائعة

- **البوت مش لاقي زر CALL/PUT:** تصميم الموقع اتغيّر — حدّث المحددات في `click_direction` في `bot_browser.py`، أو استخدم الوضع الورقي لحد ما تصلّحها.
- **البوت وقف وقال الحساب مش ديمو:** بدّل للرصيد التجريبي في Pocket Option من الواجهة، وبعدين شغّل تاني.
- **مفيش إشارات خالص:** طبيعي — استراتيجية `confluence` بتدخل بس لما 3 مؤشرات يتفقوا. جرّب استراتيجية تانية في الباك-تست، أو راجع `backtest.py`.
- **نسبة الفوز قليلة:** ده المتوقع في الخيارات الثنائية — راجع جدول `backtest.py`، ومتزوّدش المبلغ عشان تعوّض (ده بالظبط اللي بيصفّر الحسابات).

## 📜 إخلاء مسؤولية

البوت ده للأغراض التعليمية والبحثية بس. مفيش أي وعد أو ضمان بأي ربح. التداول بالخيارات الثنائية ممكن يخسّرك كل رأس مالك، وممكن يكون مقيّد أو ممنوع في بلدك، وأتمتة الواجهة مخالفة لشروط المنصة وقد تؤدي لحظر الحساب حتى على الديمو. استخدمه على حساب ديمو وعلى مسؤوليتك الشخصية.
