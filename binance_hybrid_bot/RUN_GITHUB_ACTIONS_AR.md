# تشغيل بوت Binance مجاناً على GitHub Actions — دليل الإعداد
# Run the Binance Bot FREE on GitHub Actions — Setup Guide

> البوت يشتغل على **Testnet فقط** (فلوس وهمية) — لا فلوس حقيقية، لا اشتراك شهري.
> The bot runs on **Testnet only** (fake money) — no real money, no monthly fee.

## ما هذا؟

بدل ما تدفع 7 دولار شهرياً لـ Render، GitHub نفسه يشغّل البوت **مرة كل 5
دقائق** مجاناً: كل تشغيل يفحص العملات الخمس، يطبق الفلاتر والاستراتيجية،
ويدخل صفقة Testnet إذا وجد إشارة، ثم يخرج. لا سيرفر دائم ولا تليفون شغال.

## ⚠️ حساب الدقائق المجانية — اقرأ هذا أولاً

GitHub يعطي **2000 دقيقة Actions مجاناً كل شهر** للحساب المجاني. كل تشغيل
يُحسب دقيقة واحدة على الأقل (حتى لو انتهى في 40 ثانية).

| الجدولة | تشغيل/يوم | دقائق/شهر (30 يوم) | داخل الحد؟ |
|---|---|---|---|
| كل 5 دقائق `*/5` (الافتراضي في الملف) | 288 | ~8640 | ❌ **لا — ينفد الحد بعد ~7 أيام** |
| كل 15 دقيقة `*/15` | 96 | ~2880 | ❌ لا |
| كل 30 دقيقة `*/30` | 48 | ~1440 | ✅ **نعم** |
| كل ساعة `0 * * * *` | 24 | ~720 | ✅ نعم |

**التوصية:** بعد التجربة الأولى، غيّر السطر في الملف من `*/5 * * * *` إلى
`*/30 * * * *` (تشغيل كل نصف ساعة) حتى يبقى التشغيل مجانياً طوال الشهر.
راقب الاستهلاك من: GitHub → Settings → Billing → GitHub Actions.
GitHub يوقف التشغيل تلقائياً عند نفاد الدقائق — لا يخصم منك شيئاً.

## الخطوات (تعملها أنت من موقع GitHub — لا أستطيع رفع هذا الملف بنفسي)

> **لماذا يدوياً؟** تطبيق Muse على GitHub لا يملك صلاحية كتابة ملفات
> Workflow (خطأ 403). لذلك الملف جاهز عندي محلياً، وأنت ترفعه بنفسك
> من موقع GitHub في دقيقتين.

### الخطوة 1 — رفع ملف الـ Workflow

1. افتح المستودع: https://github.com/sayedwahed/home-shopping
2. اضغط **Add file → Upload files** (أو افتح مجلد `.github/workflows` إن وجد).
3. ارفع الملف: `.github/workflows/binance-bot.yml` (موجود في مجلد المشروع
   `binance_hybrid_bot/.github/workflows/binance-bot.yml`).
   - أو: أنشئ الملف يدوياً من GitHub: **Add file → Create new file**، واكتب
     في اسم الملف `.github/workflows/binance-bot.yml`، والصق محتوى الملف كاملاً.
4. اضغط **Commit changes**.

### الخطوة 2 — إضافة مفاتيح Testnet كـ Secrets

1. في المستودع: **Settings → Secrets and variables → Actions**.
2. اضغط **New repository secret**، وأضف:
   - الاسم: `BINANCE_TESTNET_API_KEY` — القيمة: الـ API Key من Testnet.
   - الاسم: `BINANCE_TESTNET_API_SECRET` — القيمة: الـ Secret من Testnet.
   - المفاتيح من: https://testnet.binance.vision (سجّل دخول بـ GitHub، ثم
     **Generate HMAC-SHA-256 Key**، واكتب وصفاً مثل `binance-bot-testnet`).
3. **لا تكتب المفاتيح أبداً داخل الملف أو في الشات** — فقط في Secrets.

### الخطوة 3 — تفعيل Actions والتشغيل اليدوي الأول

1. افتح تبويب **Actions** في المستودع.
2. إذا طلب GitHub تفعيل Actions، اضغط **I understand my workflows, go ahead**.
3. اختر من القائمة اليسرى **Binance Hybrid Bot (Testnet, --once)**.
4. اضغط **Run workflow → Run workflow** (تشغيل يدوي للتجربة).
5. انتظر دقيقة، ثم اضغط على التشغيل لترى السجلات (Logs).
   - إذا رأيت `مرة واحدة (--once) اكتملت` أو سطور فحص العملات، فالبوت يعمل.
   - إذا رأيت خطأ في الاتصال بـ Binance، فغالباً المفاتيح ناقصة أو خاطئة —
     راجع الخطوة 2.

### الخطوة 4 — المتابعة اليومية

- السجلات: تبويب **Actions** → اضغط أي تشغيل → **trade-once** → شاهد الخطوات.
- الصفقات: محفوظة في قاعدة بيانات SQLite داخل كل تشغيل (لا تبقى بين التشغيلات
  في النسخة الحالية — سجل الصفقات على Testnet نفسه هو المرجع: صفحة
  Testnet → Orders).
- الإيقاف الفوري: عطّل الـ Workflow من تبويب **Actions** → اختر الـ Workflow
  → زر **⋯ → Disable workflow**. أو احذف الـ Secrets فيتوقف البوت عن التداول
  (سيفشل الاتصال بأمان دون إرسال أوامر).

## الأسئلة الشائعة

**هل هذا تداول حقيقي؟**
لا — Testnet فقط، فلوس وهمية، أسعار وأوامر حقيقية من Binance.

**هل يتداول وأنا نائم؟**
نعم — GitHub يشغّله تلقائياً حسب الجدولة، حتى لو تليفونك مطفي.

**ماذا لو نفدت الدقائق المجانية؟**
يتوقف التشغيل التلقائي حتى بداية الشهر التالي. لا يُخصم منك شيء.

**كيف أغيّر العملات أو المخاطر؟**
عدّل ملفات `config/` في المستودع وادفع (Push) — التشغيل التالي يستخدم
الإعدادات الجديدة تلقائياً.

**هل يمكن الترقية لـ Futures لاحقاً؟**
نعم — غيّر أمر التشغيل في الملف إلى
`python main.py --mode futures --env testnet --leverage 2 --live --once`
بعد أن يثبت السبوت نفسه أسابيع على Testnet.
